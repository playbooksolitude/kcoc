Quarto

Quarto enables you to weave together content and executable code into a finished document. To learn more about Quarto see https://quarto.org.

Running Code

When you click the Render button a document will be generated that includes both content and the output of embedded code. You can embed code like this:

1 + 1
[1] 2

You can add options to executable code like this

[1] 4

The echo: false option disables the printing of code (only output is displayed).

View 설정

설명

  • Use Visual Editor (추천)

    • 체크되어 있으면 워드(Word)나 노션(Notion)처럼 서식이 곧바로 눈에 보이는 WYSIWYG 방식의 ’비주얼 에디터’를 사용합니다. 체크를 해제하면 마크다운(Markdown) 코드가 그대로 노출되는 ’소스 에디터’로 전환됩니다.

  • Preview in Window (새 창에서 미리보기)

  • Preview in Viewer Pane (Viewer 창에서 미리보기, 추천)

  • Chunk Output Inline (코드 청크 아래에 출력)

    • 현재 체크되어 있는 옵션입니다. R 코드 블록(청크)을 실행했을 때, 그 결과(표, 그래프, 텍스트 등)를 소스 코드 바로 아래(문서 내부)에 끼워 넣어서 보여줍니다.

  • Chunk Output in Console (콘솔 창에 출력, 추천)

    • 코드 블록을 실행했을 때, 결과물을 문서 내부가 아닌 RStudio 하단의 Console(콘솔) 창이나 Plots 창에 분리하여 출력합니다. 전통적인 R 스크립트 실행 방식과 같습니다.

warning: false (경고 메시지 숨김)

penguins 데이터에는 결측치(NA)가 포함되어 있어서 그래프를 그릴 때 “이 결측치를 제거했다”는 경고(Warning) 문구가 뜹니다. 이 옵션은 그 경고 문구만 깔끔하게 지워줍니다.

  ggplot(aes(x = bill_length_mm, 
             y = bill_depth_mm, 
             color = species)) +
    geom_point()


include: false (실행하되 결과 표시 안 함)
